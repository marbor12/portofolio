Struktur Skema Supabase SQL Lengkap

Jalankan script SQL di bawah ini di SQL Editor Supabase Dashboard untuk membuat tabel `site_settings`, `projects`, `experiences`, dan `skills`:

-- 1. Tabel Utama Site Settings (Hero, About, Projects, Timeline, Skills, Contact, Marquee) CREATE TABLE IF NOT EXISTS site_settings ( id TEXT PRIMARY KEY, data JSONB NOT NULL, updated_at TIMESTAMPTZ DEFAULT NOW() ); -- 2. Aktifkan Keamanan RLS & Kebijakan Akses Baca & Tulis CMS ALTER TABLE site_settings ENABLE ROW LEVEL SECURITY; DROP POLICY IF EXISTS "Public Read Access Settings" ON site_settings; DROP POLICY IF EXISTS "Public Upsert Access Settings" ON site_settings; CREATE POLICY "Public Read Access Settings" ON site_settings FOR SELECT USING (true); CREATE POLICY "Public Upsert Access Settings" ON site_settings FOR ALL USING (true) WITH CHECK (true);
